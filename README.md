# 《弱鸡的我，一觉醒来全世界教学能力下降一百万倍，只有我保留》

> 迪化流 · 校园爽文 · 全网首发 | 目标体量：约 476 章 / 100 万字
> **当前进度：第 1 卷完稿（46 章 / 104,764 字），全部通过自校验**

一个县城的年轻教师，一觉醒来，全世界的老师都不会教书了。

他自己毫不知情，还以为是同事们"最近太累了"。

粉笔字惊为天人、叫起立惊为天人、连打开电脑都惊为天人——本书记录一个"普通班主任的平凡日常"，如何被全世界脑补成教育奇迹。

---

## 写给读者

- **爽点密度**：每章至少一个完整爽点（围观震惊 / 量化神化 / 打脸 / 处境上升），卷末章双爽点。
- **进度**：第 1 卷只覆盖 3 周剧情——慢节奏、细描写、日常神迹的满分侧写。
- **目标读者**：在现实里郁郁不得志的你。看主角把日常里没人看见的辛苦，写成万人仰望的神迹。

## 本书的创作方法论（可复用）

本项目最大的资产不是正文，而是**一套可复用的创作流水线**：

1. **原作抓取**：正版平台（番茄 API）+ 字体 OCR 解码，40 章样本（见 docs/01_抓取经验.md）
2. **定量拆书**：章均字数 / 段落粒度 / 对话占比 / 疲劳词阈值，全部实测（见 docs/02_拆书方法论.md）
3. **爆款文案拆解**：短视频脚本逐拍分析，提炼叙事骨架（见 docs/03_爆款文案拆解法.md）
4. **技能固化**：全部手法收敛为 SKILL.md，含自检清单
5. **逐章细纲**：每章标注爽点类型，写前有纲、写后有检
6. **机器自检**：check_novel.py 卡节奏参数，人机双验收

详见 [docs/00_方法论总览.md](docs/00_方法论总览.md)。
