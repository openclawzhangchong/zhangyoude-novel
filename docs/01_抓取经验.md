## 二、番茄方案（fetch_novel.py + decode_font.py）

来源：github.com/QQ-L-XX/novel-deconstruct（已通读源码确认安全：纯 requests/json/re，无 eval/exec）。

流程：
1. 书页 `fanqienovel.com/page/{bookId}` 的 `__INITIAL_STATE__` 提取章节列表（`chapterListWithVolume`）。
2. 阅读页 `fanqienovel.com/reader/{itemId}` 提取正文（HTML 内 JSON）+ woff2 字体 URL。
3. `decode_font.py`：fontTools 解析 cmap → PIL 渲染每个 PUA 字符 → ddddocr OCR → 生成 PUA→汉字映射（362 字，成功率 100%）。
4. `fetch_novel.py --mapping`：按映射替换正文。

**坑位**：
- **依赖**：ddddocr 需要 onnxruntime（本机已有）+ Pillow + fontTools + brotli，缺一装一。
- **OCR 误识**：62/362 个映射被 OCR 成字母/数字（如"操"→"x"）。解决：统计在正文中的实际出现，只修影响项（本项目仅 8 处脏话字，人工判字修复）。
- **控制台编码**：Windows 控制台 GBK，`print` 中文会 UnicodeEncodeError——所有 python 调用前 `export PYTHONIOENCODING=utf-8`。
- **免费章节上限**：番茄只放开前 10 章，其余是 ~140 字预览。**别指望番茄拿全本**。

## 三、乐文方案（crawl_lewen.py）★ 最终主力

入口由用户提供：`https://m.lewennwx.cc/11/11428/`。

### 关键发现（三次试错得出）
1. **编码是 GBK**：`r.content.decode('gbk')`——用 UTF-8 解码全是乱码（\u04a3 之类）。
2. **必须手机 UA**：iPhone UA + `--compressed`。
3. **正文容器**：`<div id="chaptercontent">`，章内分页 `{id}_2.html`、`{id}_3.html`。
4. **翻页链接**：`pb_next` 锚点——**HTML 里 href 在 id 之前**，正则必须写成 `<a[^>]*href="..."[^>]*id="pb_next"`（第一版正则要求 id 在前，导致全部抓成第 1 页）。
5. **章节 ID 双段**：该书在站内有两组 ID 段（A 段只有最近窗口，B 段 `11111102`=第 1 章起全本）。沿"下一章"链接爬即可，不要猜线性映射（B 段不线性）。
6. **限流**：连续 30+ 请求会被断连（curl exit 56）。对策：请求间隔 0.9s + 失败重试 + Session 复用。
7. **页眉残留**：每页正文里混入重复的章节标题行，清洗规则：去掉与首行相同的行 + `记住手机版网址.*` + `第(n/m)页`。

### 成果
40 章全文（第 1-40 章），每章 1900-3000 字，标题与起点官方目录逐条核对一致。

## 四、抖音内容获取（视频文案 + 图文）

### 短视频（泥石刘《一觉醒来之老师篇》）
1. 短链 `v.douyin.com/xxx` → curl 跟随重定向拿真实 video_id（iesdouyin share 页）。
2. share 页是 SPA，无 SSR 数据；`iteminfo` API 已失效（空响应）。
3. **浏览器方案**：IAB 打开 `douyin.com/video/{id}`，`document.querySelector('video').src` 拿到直链 CDN URL（非 blob）。
4. curl + Referer `https://www.douyin.com/` 下载 MP4（2.5MB）。
5. **Read 工具直接读视频**：烧录字幕逐帧可见，58 秒文案完整转写。

### 图文（张素芬）
1. share/note 也跳桌面页；正文图懒加载，DOM 里只能拿到封面。
2. **页面上下文 fetch 大法**：`tab.playwright.evaluate` 里 `fetch('/aweme/v1/web/aweme/detail/?aweme_id=...', {credentials:'include'})` —— 带_cookie 调内部接口，直接拿 `images` 列表与 `desc`。
3. 该图文实测只有 1 张图：文案=标题+图上叠字。

**通用教训**：抖音 web 端的"登录墙"只挡匿名 curl；带 cookie 的页面内 fetch 能打穿大部分只读接口。翻页/切换控件优先用键盘与 evaluate 探测，坐标点击容易误触信息流跳转。

## 五、合规红线（必读）

1. **只研究，不传播**：样本仅做定量统计与手法提炼，分析产物（报告/SKILL）不含原文句子。
2. **公开仓库零样本**：`source/`（所有抓取物）在 .gitignore 中排除。
3. **限速礼貌**：所有爬虫请求间隔 ≥0.5s，失败退避，绝不并发轰炸单站。
4. **优先正版**：凡正版平台可获取的（目录、元数据、免费章节），一律走正版；镜像只补研究必需的缺口。
