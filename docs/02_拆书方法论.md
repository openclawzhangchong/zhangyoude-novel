# 02 · 拆书方法论 — 定量指标体系

> 拆书不是写读后感，是把"感觉这书写得好"翻译成"这书在哪些可测维度上做到了什么数值"。数值能复现，感觉不能。

## 一、指标体系（7 类 22 项）

### 1. 体量指标
| 指标 | 测法 | 《无上圣魔》实测 | 用途 |
|---|---|---|---|
| 章均字数 | 去空白后 len() | 2069 字 | 定自己新书的章节规格 |
| 章字数分布 | min/max | 1934-2983 | 定容差区间 |
| 段落数/章 | 按空行分 | 59-104，均值 80 | 定段落粒度 |
| 平均段落字数 | 总字数/段数 | ≈25 字 | **最关键的节奏指标** |

### 2. 对话密度
| 指标 | 实测 | 用途 |
|---|---|---|
| 对话段占比 | 9%-49%，均值 25% | 定每章对话配额；群像章可到 49%，独白章不低于 12% |

### 3. 句法节奏
| 指标 | 实测 | 用途 |
|---|---|---|
| 句均长（以。！？；…断句） | 16.6-25.7，均值 20 | 短句流的量化定义 |
| ≤15 字短句占比 | 22%-57%，均值 38% | "碎段流"的硬证据 |

### 4. 疲劳词（防止 AI 味）
逐词 count，实测均值摊到每章：顿时 1.2 / 似乎 1.0 / 居然 0.65 / 突然 0.8 / 随即 0 / 紧接着 0.2。
→ **由此定出新书阈值**：顿时≤2、似乎≤1、突然≤1、居然≤1、仿佛≤1（每章）。

### 5. 风格签名（该书的指纹）
| 特征词 | 40 章总频 | 解读 |
|---|---|---|
| 日记体引言 | 40/40 章 | 每章开头必有，编号递增——签名装置 |
| 魔神 | 59 | 世界观标签词 |
| 呃/啧/呵呵/等等/脑子 | 16/16/19/18/15 | 主角吐槽口头禅库 |

### 6. 结构指标
- 章名长度：2-4 字名词短名为主
- 每章误会节拍：1-2 个完整循环
- 章末钩子：新误会/新威胁/反转三选一

### 7. 商业指标
- 总体量/在更章数 → 日更节奏
- 章均字数 × 完结章数 → 全书规模预估

## 二、拆书流程（五步）

```
① 样本获取：≥30 章全文 + 全书目录（含每章字数）
② 清洗：去页眉残留/水印/分页标记（正则批处理）
③ 扫描：脚本跑 22 项指标，出数据表
④ 结构分析：抽读 6-8 章全文，标注每个场景的功能
     （激励事件/世界观渗透/误会升级/钩子）
⑤ 公式化：把"每章怎么写"写成可执行模板
```

## 三、从数据到 SKILL 的映射

| 实测 | 新书规则 |
|---|---|
| 章均 2069 | 新书 2100 ± 容差 1900-2900 |
| 段均 25 | 新书均段长 ≤32（对话章放宽） |
| 对话 25% | 新书 25% ±（10-80% 区间按场景） |
| 疲劳词 | 新书按实测×1.5 定阈值 |
| 日记体 40/40 | 新书移植为《教学日记》格言，编号递增 |
| 章名 2-4 字 | 新书沿用（板书/起立/推门/放榜） |

## 四、拆书的边界

- 拆的是**结构和节奏**，不是句子。分析产物中禁止出现原文连续 7 字以上片段。
- 数据表格可以公开（这是统计事实），原文不行。
- 拆书的目的：让新书"像它一样好读"，而不是"像它"。
