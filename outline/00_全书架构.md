# 《弱鸡的我，一觉醒来全世界教学能力下降一百万倍，只有我保留》全书架构

> 目标体量：476 章 ≈ 100 万字（章均 2100 字）。
> 类型：迪化流 · 校园日常 · 轻松爽文 · 无感情线。
> 主角：张有德，男，40 岁，某省某县"县第一中学"高中数学教师兼班主任，教龄 17 年，二级教师职称卡八年。
> 写作规范：所有正文按 SKILL.md 执行。

## 一、一句话故事

全世界老师的"教学能力"一夜之间暴跌一百万倍，全人类没人能教任何人任何东西；只有县城老教师张有德毫发无损——而他自己根本不知道，他以为"教书就这么难，同事最近是不是太累了"。

## 二、世界观铁律（全书不许违背）

1. **异常范围**：所有"教学行为"相关能力：讲题逻辑、板书、表达、组织课堂、改卷判断、备课设计，全部崩坏。老师本人不自知（都觉得自己"讲得挺明白的"）。
2. **学生正常**：学生智商、勤奋度正常，但没有教学输入就学不会。世界-learning 崩溃是缓慢蔓延的：先是听不懂课，然后考不上试，然后技术断代、科研停摆——本书只写到"社会性焦虑"层面，不写文明崩坏（那是卷6以后的事）。
3. **张有德不知情**：他的认知锚点是"教书很苦很正常"。别人越菜他越觉得"现在年轻人不像我们当年能吃苦"。**他到全书结束都不被告知真相的全貌**（他可以在很后期隐约察觉"世界好像有点怪"，但绝不允许有人对他挑明）。
4. **误会不可说破**：任何角色一旦接近真相（"全世界只有他正常"），就被新的误会岔开。读者全知，角色全盲，主角半盲。
5. **原因悬置**：为什么是他？全书用一个贯穿伏笔（17 年教学日记）暗示，卷7 给一个"温柔的宇宙玩笑"式解释，不搞科学设定硬解释。

## 四、爽点节奏总纲

- **三章一小爽**：一个误会循环完整走完（班内级别）。
- **十章一中爽**：误会波及新圈层（校内/家长/县里），主角地位实体上升。
- **卷末大爽**：卷级名场面（统考逆袭/公开课封神/大赛碾压/央媒报道），配合"神迹清单"解锁大层级行为。
- **进度要求**：卷1 只覆盖 3 周剧情时间（用户要求：进度要慢、要细节）。后期允许加速但不许跳年。
- **每个"神迹"首次出现必须三拍写满**：动作细节拉满 → 旁观者生理反应 → 群体脑补升华。重复出现必须换观察者/换方向/换后果。

## 五、误会爆炸的传播链（世界观级设定）

```
张有德做了一件平常事
→ 班级内：学生窃语（当堂）
→ 教师间：同事背后议论（当天）
→ 学校层：主任/校长定性（一周内）
→ 家长层：家长会/群里疯传（即时，家长最疯）
→ 媒体层：县电视台/公众号《教育观察君》"神秘教师"系列（两周）
→ 官方层：县教育局调研 → 市里蹲点 → 省里立项 → 教育部工程
```

每一层有专属脑补风格：学生玄学化、同事阴谋化、领导政绩化、家长神话化、媒体戏剧化、官方体系化。

## 七、贯穿梗（全书复用的喜剧资产）

1. **《一个普通班主任的教学日记》**：每章开头格言，编号递增。后期被 leaks 传抄成《张氏教学法》，编号被考据党研究出规律。
2. **"是不是太累了"**：张有德对一切异常的标准解释，后期成为全县教师群体的口头禅。
3. **二级教师职称**：全中国最高危误会点——所有人都想不通为何"国宝级大师"只是二级教师，职称评审材料被各级研究，最后惊动人事部门。
4. **王铁柱的赌局**：差生王铁柱逢人就赌"张老师下节课还会惊到你们"，赌赢了一辈子零食。
5. **陈朵朵的观察日记**：课代表偷记"张老师行为观察录"，越记越像《圣典》注疏。
6. **周锐的论文**：年轻名校硕士同事从怼到粉，论文题目从《论基础教学的经验主义误区》一路改成《张有德现象研究》。
